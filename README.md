# Matchup Hub

Every NFL game this week with your fantasy players, your opponents' players, and the weather at kickoff, across all your Sleeper leagues.

Live at https://matchuphub.netlify.app

- `index.html` is the whole site (styles and code included).
- `share-card.png` is the picture shown when the link is shared.
- Netlify redeploys automatically whenever this repository's `main` branch changes.
